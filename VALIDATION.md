## Что проверено

- Точные веса готовности, отсутствующие значения, максимум 100, история изменения.
- Создание, приватность черновиков, список владельца, публикация, публичный каталог.
- Заявки, защита от дубликатов, выбор одной команды, отклонение остальных, закрытие приёма.
- Права владельца, неверные ID и данные, запрет редактирования опубликованного брифа.
- Ответы бизнеса не перезаписываются AI, неподтверждённые цитаты удаляются.
- Реальный установленный OpenAI SDK: schema-constrained request и parsing с mock HTTP-транспортом, ошибочный JSON, отказ модели.
- NVIDIA: валидный результат, отсутствующий ключ, тайм-аут, HTTP-ошибка, пустой или повреждённый ответ.
- В браузере: бизнес публикует демо; студент в отдельном контексте подаёт заявку; бизнес выбирает команду; выбор виден после обновления.
- В браузере: при отсутствии OpenAI-ключа текст не теряется, ручное заполнение даёт реальный переход 0 → 100.
- Мобильные страницы 390px не выходят за ширину экрана; desktop и mobile скриншоты осмотрены.
- Отдельный HTTP smoke на временной SQLite: сервер перезапускается, задача, история баллов и SELECTED сохраняются.

## Границы проверки

Живые вызовы OpenAI/NVIDIA **не выполнялись**: ключи не предоставлены. GitHub Actions не запускался удалённо. Внешнего deployment нет. Нагрузочное тестирование и production-аудит безопасности не проводились.

Первоначальная загрузка Chromium с CDN не удалась; совместимая версия была успешно установлена с резервного адреса Playwright. Итоговые браузерные тесты прошли полностью.
